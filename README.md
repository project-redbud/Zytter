# 学园激斗事件簿（Zytter）· 现代 C# 重制版

> **《学园激斗事件簿》**（英文名 Zytter）是基于《黑之洗礼》世界观的一对一回合制对战游戏。
> 原版由 **Team Zy** 开发、2019 年 12 月发布，后续由 **叶子（yeziuku）** 维护，2021 年 9 月停止维护并闭源，最终公开版本为 **v2.0beta（20210702）**。
>
> 本项目由原版开发成员兼后续维护者**叶子**主持重制：**Godot 4.7 (C#) 客户端 + ASP.NET Core 8 SignalR 权威服务器 + SQLite/EF Core**，保留原版全部玩法规则（英雄、技能、Buff、商店、匹配、回合战斗、排行榜）。《学园激斗事件簿》现已列入[红芽计划（Project Redbud）](https://redbud.fun)，游戏设计说明与历史更新日志见[红芽百科](https://wiki.wrss.org/学园激斗事件簿)。

## 游戏规则

### 玩法

两名玩家通过 B/P（禁用/选用）从英雄池中各选取 3 名英雄，进行 1v1 回合制对战。**胜利条件：击杀对方所有英雄。** 当回合耗尽且未分出胜负时，依次按以下规则判定：

1. 英雄数量多的玩家获胜；
2. 英雄当前生命值百分比高的玩家获胜；
3. 具体生命值高的玩家获胜；
4. 匹配房间拥有者获胜。

### 回合与行动

- 初始 **35 回合**，可在商店购买「回合延时道具」扩展 5 个回合。
- 行动优先权由**行动力算法**决定：行动力高者先手；行动力相同（或双方同时使用"无视行动力"技能）时，匹配房间拥有者先手。
- 每回合流程：励兵秣马（准备）→ 运筹帷幄（选择行动）→ 兵戎相见（结算）→ 回合结束（发金币、回复、低血保底）。
- 可选行动：技能 Q/W/E/R、普通攻击、使用道具、放弃。

### 伤害算法

- **物理伤害**：`伤害 − 对方物理护甲 ×（1 − 你的物理穿透）`
- **普通攻击**：`你的攻击力 − 对方物理护甲 ×（1 − 你的物理穿透）`
- **魔法伤害**：`伤害 − 对方魔法防御 ×（1 − 你的魔法穿透）`

### 金币与商店系统

- 每回合结束后每名玩家 **+1 金币**；击杀对方英雄 **+3 金币**。
- 每对对方造成 **15（30）点物理伤害**，掠夺对方 **1（2）块金币**。
- **商店回合**：第 5、12、19、26、31 回合结束后进入（37 回合后每 5 回合一次）；前 35 回合的商店开始时 **+2 金币**，之后的商店回合 **+4 金币**。
- **加时赛商店（35 回合后）**：提供「吃装备」效果——再次购买已拥有的装备将永久获得该装备属性（无需装备，个别装备不适用）；且不再出售回复类道具。

### 属性补偿与续航

- 第 **6、13、20、27** 回合开始时（前 4 个商店回合结束后），双方英雄分别提升 **+4、+4、+5、+5 点生命上限**（并回复等量生命值），同时每次获得 **5% 物理伤害减免**（共 4 次，最高 +20%）。
- 每回合结束，生命值低于最大生命值 30% 的英雄回复 7% 最大生命值。

### 结晶之力

英雄**上场 5 回合**或**累计造成 20 点魔法伤害**后即可激活结晶之力（从 3 个备选分支中选择 1 个），强化自身技能（奕阳、郈与却、郑心予、苏璟静专属）。

### 控制效果

| 效果 | 说明 |
|---|---|
| 攻击不能 | 行动阶段无法使用普通攻击 |
| 施法不能 | 行动阶段无法使用技能 |
| 战斗不能 | 行动阶段无法使用普攻和技能 |
| 行动受限 | 允许在行动阶段前使用复苏类道具；不使用则行动阶段被跳过 |
| 完全行动不能 | 行动阶段被跳过 |

### Buff 叠加规则

- 「持续 X 回合」＝ 包括本回合和接下来的 X−1 个回合；
- 未注明持续时间的 Buff 仅本回合内有效；
- 未注明 Buff 承受者时，默认为技能使用者。

## 快速开始

```powershell
# 1. 启动服务器（首次运行自动迁移 SQLite 数据库）
dotnet run --project src/Zytter.Server          # 监听 http://0.0.0.0:17717

# 2. 启动客户端（Godot 4.7 Mono）
& ".\Godot_v4.7-stable_mono_win64.exe" --path src\Zytter.Client

# 3. 无头机器人对战（自动化验证，两个终端各开一个；第二实例加 -- --nobgm 静音）
& ".\Godot_v4.7-stable_mono_win64_console.exe" --path src\Zytter.Client --headless -- --bot --botname=botA
& ".\Godot_v4.7-stable_mono_win64_console.exe" --path src\Zytter.Client --headless -- --bot --botname=botB

# 或一键脚本（自动双开，第二个窗口静音）
play-two-clients.bat
```
